# The Lifecycle of a Project

The Organic Project Cycle is a physical workflow. Here is exactly how a project moves from raw idea to final release within this vault.

## 1. The Aquifer (Inception)
Not every idea is ready to be a project. Raw inspiration, interesting links, and half-formed thoughts should be dumped directly into the `Fen_Resource` folder. This is your compost heap. Let them sit there without the pressure of execution. 

## 2. The Spring (Spawning a Project)
When a concept in the `Fen_Resource` gathers enough weight to demand action:
1. Create a new markdown note in the `02_Active_Projects` folder.
2. Apply the **Master Project Template**.
3. Set the `biome_stage` property to `"[[01_Fen|Fen]]"`.
4. The project will now automatically appear in the first column of your `01_The_Cycle_Board`.

## 3. The Flow (Execution)
Open `01_The_Cycle_Board`. Your job is to move the project from left to right.
* **Audit before you move:** Open the project card and review the diagnostic checklist for your current stage. You cannot drag a card to the **Mountain** until the **Forest** checklist is complete.
* **Log your momentum:** As you work, log your daily efforts in the project file using the `- [ ] #win` syntax. These will automatically aggregate on your `AMWAP Master Log`.

## 4. The Eddies (Getting Stuck)
Projects rarely flow perfectly. When momentum stops, get the project out of the active current so it doesn't block other work.
* If you realize you are missing vital resources or scope clarity before the sprint, drag the card to the **Tundra**.
* If you burn out after the Mountain or hit a wall in the Field, drag the card to the **Desert**.
* *To escape a set-aside:* You must either acquire the missing resource (re-entering the flow) or accept defeat and move the file back to `Fen_Resource` to compost.

## 5. The Estuary (Resolution)
A project exits the active board in only one of two ways:
* **The Ocean (Success):** The project survives the Delta and is released to the public. You surrender control. Move the markdown file out of `02_Active_Projects` and into `05_Ocean_Archive`. 
* **The Compost (Evaporation):** The project dies in the Tundra or Desert. Move the markdown file out of `02_Active_Projects` and into `Fen_Resource`. The project is dead, but its text, research, and lessons become the nutrients for whatever grows next in the Fen.
