# The Delta
## The Conceit
The waters joined together in the [[04_Field|Field]] start to spread back out again, interacting in swamps and deltas on the way to the [[06_Ocean|Ocean]]. This is the phase where the project is exposed, tentatively and with constraint and care, to the feedback of the public consciousness. 

Playwrights conduct cold reads and rehearsals here. Painters have peer showings and small gallery openings. Dancers perform new choreography recitals, then showcases and so on.
## The Objective
Soft launch and controlled public exposure.
## How to Engage
The project must interact with the public consciousness, but within defined, constrained environments. Measure the audience interaction carefully.
## Beware This
Treating the Delta like the Ocean by abandoning constraints too early, or treating it like the [[04_Field|Field]] by hiding from true public reaction. Being unwilling to move back to [[03_Mountain|Mountain]] or [[04_Field|Field]] if needed.
## When to Move On
- [ ] A constrained public trial (soft launch, rehearsal, beta test) is completed.
- [ ] Public reaction/interaction is measured and finalized.
- [ ] The project is completely finalized with zero remaining revisions.
