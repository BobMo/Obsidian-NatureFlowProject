# The Tundra (upstream hold)
# The Conceit
Water is in a frozen state (ideas are inaccessible). Projects that are too large to be confidently moved up the mountain, or too loose, or too imposing are set aside to roam apart around the Tundra without adding ideas or increasing (due to scant resources available in the Tundra). Everything on this side (Fen, Forest, Mountain) can move things into the Tundra, and from Tundra, it can go to anything back on this side.
# The Objective
A holding zone for upstream projects missing the necessary resources, scope constraint, or confidence to sprint.
# How to Engage
Active work stops. Do not attempt to grow or expand the project while it is frozen here. 
# Beware This
Using the Tundra as a guilt-free graveyard to avoid permanently deleting bad ideas.
# When to Move On
- [ ] *To re-enter flow:* The missing resource, constraint, or confidence has been acquired.
- [ ] *To evaporate:* The project is no longer aligned and can be moved back to `Fen_Resources` for fertilizer.
